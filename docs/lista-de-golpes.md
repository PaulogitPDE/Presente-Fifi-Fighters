# Lista de golpes do Fifi Fighters

Para renomear: escreva o nome novo na última coluna e me devolva o arquivo (ou só me diga "golpe X vira Y").
Os nomes aparecem na tela sem acento (a fonte do jogo não tem acentos); pode escrever com acento que eu ajusto.

## Golpes básicos (iguais para todos)

| Comando | Golpe | O que faz | Dano |
|---|---|---|---|
| Soco | Soco | Golpe rápido, de pouco dano. | 50 |
| Chute | Chute | Mais lento que o soco, com mais alcance e dano. | 72 |
| Baixo + Soco | Soco agachado (gancho) | Soco rápido sem levantar. | 40 |
| Baixo + Chute | Rasteira | Derruba o oponente; só é defendida agachado. | 62 |
| Soco no ar | Soco pulando | Golpe aéreo; só é defendido em pé. | 60 |
| Chute no ar | Voadora | Chute pulando; só é defendido em pé. | 72 |
| Perto + Soco + Chute | Agarrão | Agarra e arremessa. Quem é agarrado escapa apertando os dois logo. | — |
| Acertou soco ou chute? Poder | Combo | Emenda o golpe normal com o especial. | — |
| Frente, frente / trás, trás | Dash / recuo | Avança rápido ou recua com invencibilidade curta. | — |
| Segurar para trás | Defesa | Bloqueia (agachado defende rasteira). | — |

A vida de cada lutador é 1000. Nos golpes de vários acertos, o dano é de cada acerto.
